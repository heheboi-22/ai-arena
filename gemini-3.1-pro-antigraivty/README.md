# Pocket World

A polished, interactive 3D diorama of a tiny floating island built with Three.js, Vite, and TypeScript.

## Quick Start

### Installation
Ensure you have `npm` installed. Then run:
```bash
npm install
```

### Development
Start the local development server (with hot module replacement):
```bash
npm run dev
```

### Production Build
Build the optimized application:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## Features
- **Dynamic 3D Island:** Entirely procedural generation without external models.
- **Interactive Time of Day:** Watch colors and shadows seamlessly shift from dawn to night.
- **Dynamic Weather System:** Soft rain elements with smooth transitions.
- **Reactive Environment:** Wind strength affects rain angle, cloud drift speed, windmill rotation, and tree sway.
- **Interactions:** House lights toggle via click/tap or UI panel.
- **Responsive Controls:** Custom UI and orbit constraints for intuitive framing.
